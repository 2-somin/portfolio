## 작업 1 — 2-somin.github.io (Jekyll 메인 사이트)

### 1-1. OG 메타데이터 구성

**`_config.yml` 변경사항**

```yaml

description : "도예학과 출신 UI/UX 디자이너 이소민의 포트폴리오"
og_image    :        # 비어 있음
og_description:      # 비어 있음
locale      : "en-US"

# 변경 후
title       : "Product Designer 이소민"
description : "Product Designer 이소민의 포트폴리오. 사용자 경험을 섬세하게 설계합니다."
og_image    : "og-image.png"
og_description: "Product Designer 이소민의 포트폴리오. 사용자 경험을 섬세하게 설계합니다."
locale      : "ko_KR"
```

### 1-2. OG 이미지 생성 (`images/og-image.png`)

- **사이즈**: 1200 × 630px (카카오톡/SNS 표준)
- **생성**: Node.js + `sharp` 라이브러리로 SVG → PNG 변환
- **디자인**: 다크 네이비 배경 / `UXUI / PRODUCT DESIGNER` 서브타이틀 / `Lee Somin` 메인 텍스트 / 골드 accent bar

**디자인 수정 이력**
- 초안: 서브타이틀 `PRODUCT DESIGNER`, 메인 텍스트 `이소민` (한글)
- 최종: 서브타이틀 `UXUI / PRODUCT DESIGNER`, 메인 텍스트 `Lee Somin` (영문 세리프)

### 1-3. 파비콘 리디자인

- 기존: Wikipedia 학술 아이콘 (파란색 졸업모)
- 변경: `이` 글자, 다크 네이비 배경(`#1a1a2e`), 골드 텍스트(`#c9a97a`)
- 생성 파일: `favicon.svg`, `favicon-32x32.png`, `favicon-192x192.png`, `favicon-512x512.png`, `apple-touch-icon-180x180.png`

### 1-4. `seo.html` OG 태그 보완

| 항목 | 수정 내용 |
|------|-----------|
| `og:type` | 일반 페이지에 `website` 기본값 추가 |
| `og:image` | `site.og_image` 폴백 로직 추가 |
| `og:image:width/height` | `1200`, `630` 명시 |
| `og:locale` | `en` → `ko_KR` |

### 1-5. og:image URL 이중 prepend 버그 수정

```liquid
{# 버그: base_path(https://...)에 site.url을 또 prepend #}
{{ site.og_image | prepend: "/images/" | prepend: base_path | prepend: site.url }}
{# → https://2-somin.github.iohttps://2-somin.github.io/images/og-image.png ❌ #}

{# 수정 #}
{{ site.og_image | prepend: "/images/" | prepend: base_path }}
{# → https://2-somin.github.io/images/og-image.png ✅ #}
```

### 1-6. og:description 오출력 수정

`about.md`에 `description` 프론트매터가 없어 Jekyll이 `page.excerpt`(본문 첫 줄)를 OG description으로 출력하던 문제. 프론트매터에 `description` 명시로 해결.

### 1-7. 이름 및 프로필 이미지 변경

```yaml
# _config.yml
name   : "이소민" → "Lee Somin"
avatar : "my-notion-face-transparent.png" → "IMG_black.jpg"
```

## 작업 2 — portfolio 레포 (커스텀 HTML)

### 2-1. OG 태그 신규 추가

`index.html` `<head>`에 OG 6개 태그 및 파비콘 링크 추가:

```html
<meta property="og:type"        content="website">
<meta property="og:url"         content="https://2-somin.github.io/portfolio/">
<meta property="og:title"       content="Lee Somin · Product Designer">
<meta property="og:description" content="Product Designer 이소민의 포트폴리오. 사용자 경험을 섬세하게 설계합니다.">
<meta property="og:image"       content="https://2-somin.github.io/portfolio/og-image.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:site_name"   content="Product Designer 이소민">
<meta property="og:locale"      content="ko_KR">
```
